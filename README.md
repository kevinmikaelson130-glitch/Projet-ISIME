# Projet ISIME

## Description

Projet de fin d'études réalisé pour l'Université ISIME.

Ce site web institutionnel a été conçu pour présenter l'université, ses formations, ses actualités et faciliter la communication avec les visiteurs.

## Fonctionnalités

- Présentation de l'université
- Gestion des formations
- Publication des actualités
- Formulaire de contact
- Interface responsive (mobile, tablette et ordinateur)

## Technologies utilisées

### Frontend
- HTML5
- CSS3
- JavaScript
- React.js
- TypeScript
- Tailwind CSS

### Backend et Base de données
- Supabase
